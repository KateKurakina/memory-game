# Memory Game

Memory Game — браузерная игра на развитие памяти, в которой необходимо находить пары одинаковых карточек.

## Описание проекта

Игровое поле состоит из **16 карточек**, образующих **8 пар**. В начале игры все карточки закрыты и располагаются в случайном порядке.

Игрок по очереди открывает карточки и пытается найти одинаковые пары. За каждую попытку увеличивается счётчик `Tries`, а за найденную пару — счётчик `Score`.

После нахождения всех пар появляется модальное окно с результатом игры.

## Функциональность

* автоматическое создание игрового интерфейса с помощью JavaScript;
* 16 карточек / 8 пар;
* случайное расположение карточек;
* возможность начать новую игру без перезагрузки страницы;
* автоматический подсчёт попыток;
* подсчёт найденных пар;
* блокировка остальных карточек во время проверки несовпадающей пары;
* модальное окно после завершения игры;
* модальное окно с таблицей лидеров;
* сохранение результатов в `localStorage`;
* отображение 10 лучших результатов;
* сортировка результатов по количеству попыток и дате;
* закрытие модальных окон кнопкой, по клику на затемнённую область и клавишей `Escape`.

## Запуск проекта

### Локальный запуск

Для запуска проекта необходим локальный HTTP-сервер, так как данные карточек загружаются из `cards.json` с помощью `fetch()`.

1. Клонировать репозиторий:

```bash
git clone https://github.com/KateKurakina/memory-game.git
```

2. Перейти в директорию проекта:

```bash
cd memory-game
```

3. Запустить проект через локальный сервер.

Например, при использовании Visual Studio Code можно установить расширение **Live Server**, открыть `index.html` и выбрать:

**Open with Live Server**

После этого приложение откроется в браузере.

> Не рекомендуется открывать `index.html` напрямую через `file://`, поскольку браузер может заблокировать загрузку `cards.json` через `fetch()`.

## Управление

* **New Game** — начать новую игру и перемешать карточки.
* **Leaders** — открыть таблицу лучших результатов.
* **Клик по карточке** — открыть карточку.
* **Escape** — закрыть модальное окно.
* **Кнопка ×** — закрыть модальное окно.

## Таблица лидеров

После победы результат автоматически сохраняется в `localStorage`.

В таблице отображаются:

* позиция;
* количество попыток;
* дата завершения игры.

Хранятся **10 лучших результатов**.
